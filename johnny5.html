Fun projects / Johnny5

Johnny5, my home AI agent.

A personal AI agent hosted on OpenClaw, running on a Mac mini in my house. It sends my daily briefings, keeps me learning, and powers a few things I built just for fun. Local models do most of the work; Claude steps in where it's worth it.

How it's built

Inputs

  • Slack: chat with it, and it posts to channels
  • Its own Google account: calendar, email
  • Podcasts, RSS and newsletters
  • Public APIs: sports, games, markets

The agent

  • OpenClaw hosts the agent on the Mac mini: chat, memory, schedules
  • Claude Haiku for conversation; Sonnet only for research write-ups
  • Ollama local models for summaries, scoring and extraction
  • Python scripts for everything deterministic

Outputs

  • Morning briefs and digests in Slack
  • DMs that ask a question and file the reply
  • Reports and research documents
  • Small web apps on the home network

What it does

Every morning

Briefings

  • Downloads and transcribes three news podcasts with Whisper, then posts one digest
  • Summarizes a daily tech-strategy newsletter
  • A family morning brief with markets
  • A daily calendar check
Every week

Learning & growth

  • Pulls ~40 AI and data feeds nightly, scores each against my interests, posts the best on Mondays
  • Transcribes new episodes of AI and product podcasts
  • Asks me every Friday what moved that week, and turns the answers into a monthly recap
Built on it

Things I made

  • Deep research: ask a question in Slack and Claude plans the search, local models search and distill the sources, and Sonnet writes the final report
  • The Kop: a Roku channel for Liverpool FC that jumps straight into the right streaming app
  • Love notes: a small family ritual it prompts and collects
Behind the scenes

Looking after itself

  • Nightly memory consolidation on a local model
  • Weekly job-policy enforcement and config backup
  • Weekly software update check, nightly cleanup

Design principles

  • The box does the heavy lifting. Local models first. Paid API calls only where a local model falls short, and then the smallest model that's good enough.
  • Code where code works. Scheduled jobs are plain scripts that call a local model only when they need one. An LLM wrapped around a script once hid its failures, so they're gone.
  • Small blast radius. No personal or financial data on the box, its own accounts, least-privilege tokens, and a secrets scanner on every commit.
  • Untrusted input stays data. Email, feeds and web pages can carry prompt injection, so they only reach prompts that have no tools.
  • Fail loudly. Every job exits non-zero on failure and alerts a status channel; weekly checks catch drift.
  • Benchmark before switching. Model changes are tested on real tasks first, like Gemma 4 vs Qwen 3.5 on 20 real extractions.
